# Contributing

CubicOne is a personal fork of [T3 Code](https://github.com/pingdotgg/t3code). It is maintained for its author's own use and does not run a public contribution process.

## Developer setup

See the [development runbook](docs/operations/development.md#first-checkout) for the initial checkout, development commands, tests, and platform-specific desktop packaging prerequisites.

## Branches

- `main` mirrors `upstream/main` and is never developed on.
- `cubicone` is the default and development branch.

## Bugs and ideas

Open an issue in this repository. Bugs that reproduce on upstream T3 Code are better reported there, since fixes land upstream first and flow into this fork on the next merge.

## Pull requests

Small, focused fixes are welcome. Keep the diff to one concern, use a conventional commit title such as `fix(web): ...`, and describe the problem and the fix in the body. Large features or rewrites are unlikely to be merged.
